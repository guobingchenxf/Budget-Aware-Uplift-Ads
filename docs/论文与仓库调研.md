## 2. 论文

### 2.1 已核验的论文

#### （1）UpliftBench: Revealing Outcome-Regime and Objective Mismatch in Uplift Evaluation ✅

- **作者**：Binshuang Li（Independent Researcher, USA）
- **年份**：2026
- **URL**：`https://arxiv.org/html/2608.00915v1`
- **核验方式**：本次实际访问并提取了其主张
- **核验到的关键结论（原文表述）**：
  - 连续结果下 "Qini shows no detectable alignment with effect accuracy"，而 "AUUC is consistently more aligned"；
  - "ranking metrics are structurally insufficient for a sign-threshold policy because they discard the score level"；
  - "calibrating the decision threshold removes 81% of the Qini-selection regret"；
  - 其基准数据集包括 IHDP、Jobs、Synthetic、**Hillstrom**、Lenta、X5、MegaFon、Criteo。
- **本项目实际借鉴点**：
  1. 不单独依赖 Qini，同时报告**策略价值（预算分配口径）**与校准；
  2. 本项目 conflicting 场景中"所有策略归一化 Qini 均为负"的实测结果，
     与该文"排序指标丢弃分数量级信息"的论点一致；
  3. 项目初期的"响应模型 vs uplift 模型"对比设计受该文启发。
- **⚠️ 使用风险**：这是**单作者预印本，未见同行评审记录**。
  在面试或简历中引用时应表述为"一篇 2026 年的 arXiv 预印本指出…"，**不要表述为"权威结论"**。

## 4. 调研结论如何影响技术决策（可追溯）

| 调研发现 | 对本项目的具体影响 |
|---|---|
| Criteo 官方链接不可达 | 改用 Hillstrom 作为主数据；在 README 与文档中显式标注不可达事实 |
| Criteo 的许可为 CC BY-NC-SA 4.0 | 即使后续接入，也**不得商用**；已记录在数据文档中 |
| UpliftBench 指出 Qini 的失效场景 | ① 主指标改为**预算约束下的策略价值**；② 强制加入**自助法置信区间**；③ 在报告中专门讨论 Qini 失效 |
| Hillstrom 无成本/预算字段 | 所有成本与预算明确声明为**模拟变量**，并在 README、配置注释、代码 docstring 三处标注 |
| Hillstrom 是随机实验 | 允许使用 Qini 形式的无偏增量估计量（否则需要倾向性加权） |
| GitHub 不可达 | 核心算法自行实现 + 单元测试；不引入无法核验的第三方依赖 |
| 未找到新方法的可验证实现 | 不实现"增强模型"，明确列入后续路线，**不伪装已完成** |
